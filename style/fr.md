# French (fr)

- Address the user as **vous**: *Connectez-vous*, *Choisissez un profil*.
- Buttons use the infinitive: *Annuler*, *Enregistrer*, *Réessayer*.
- Typography: a narrow no-break space (U+202F) before `: ; ! ?` and inside « » guillemets;
  write the ellipsis as one character …
- Sentence case, like the English.
- Plurals: `one many other`. `one` covers 0 and 1 (*0 saison*, *1 saison*); `many` is for
  whole millions (*1 000 000 de saisons*).
