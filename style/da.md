# Danish (da)

## Voice

- Address the user as **du** (*dig*, *din*, *dit*, *dine*): *Log ind*, *Vælg en profil*, *Prøv
  igen*. Never *De*, and never *I*: text that speaks to a group still addresses the reader
  (*Se sammen, uanset hvor du er*).
- Buttons, menu items and the choices of a picker use the imperative, as Apple, Google and
  Microsoft do in Danish: *Annuller*, *Gem*, *Slet*, *Luk*, *Prøv igen*, *Brug
  undertekstindstillinger*. Instructions in sentences use the imperative too: *Vælg et
  bibliotek*. Where English uses a noun as a label (*Playback*, *Downloads*), use the noun
  (*Afspilning*, *Downloads*).
- An on/off value is *Til* / *Fra*, whatever it switches.
- Status words on one screen use the same form: a request's status is a past participle
  (*Anmodet*, *Godkendt*, *Afvist*, *Mislykkedes* or *Fejlet*), also in titles and labels on the
  same screen. A status for something in progress uses the passive *-s* form or *I gang*:
  *Afspilles*, *Indlæser …*, *Bufferer …*.
- Sentence case, like the English. Danish doesn't capitalize nouns, languages, nationalities,
  weekdays or months (*dansk*, *engelske undertekster*, *mandag*). Feature names keep their own
  capitals (*Watch Party*, *Autoscan*). English all-caps labels stay all caps (*LIVE*).
- A library type or tab name used as a common noun inside a sentence is lowercase (*ingen
  filmbiblioteker*), not quoted as the tab name.
- Quotation marks ”…” (the same closing mark on both sides, as Danish typesetting does). Write
  the ellipsis as one character … and space it exactly as the English does: no space before
  it when the English has none, as Apple writes Danish (*Indlæser…*, *Søger…*, *Vælg studie…*).
- Apostrophe: the typographic ’. Danish forms the genitive with a bare *-s* (*Silos*,
  *Jellyfins*, *profilens*); after a name that ends in *s*, *x* or *z* add only ’ (*Sonarrs* but
  *Plex’*). Use ’ before an ending on an abbreviation or a number (*tv’et*, *pc’er*, *USA’s*,
  *DVD’er*).
- Be gender-neutral where it reads naturally: *person*, *gæst*, *værten* or *den, der står for
  festen*.

## Vocabulary

- Standard Danish (rigsdansk) as Apple, Google and Netflix write it in Denmark.
- **Danish, not Norwegian.** Danish and Norwegian Bokmål look alike; never use the Norwegian
  form. Check for these in particular:

  | Danish (write) | Bokmål (never) |
  |---|---|
  | *indstillinger*, *afspil*, *afspilning* | *innstillinger*, *spill av*, *avspilling* |
  | *gem*, *slet*, *luk*, *søg*, *tilføj*, *annuller* | *lagre*, *slett*, *lukk*, *søk*, *legg til*, *avbryt* |
  | *af*, *efter*, *nu*, *hvad*, *sprog*, *tilbage* | *av*, *etter*, *nå*, *hva*, *språk*, *tilbake* |
  | *bruger*, *brugernavn*, *adgangskode* | *bruker*, *brukernavn*, *passord* |
  | *enhed*, *sikkerhed*, *mulighed* (‑hed) | *enhet*, *sikkerhet*, *mulighet* (‑het) |
  | *fejl*, *køb*, *skabe*, *tilgængelig* | *feil*, *kjøp*, *skape*, *tilgjengelig* |
  | *afsnit* (an episode), *sæson* | *episode*, *sesong* |
  | definite plural *-erne* / *-ene*: *serierne*, *enhederne*, *brugerne* | *seriene*, *enhetene*, *brukerne* |
  | *mislykkedes*, *ikke* … *endnu* | *mislyktes*, *ikke* … *ennå* |

- Established Danish UI terms where they are common: *Indstillinger*, *undertekster*,
  *bibliotek*, *adgangskode*, *enhed*. Keep product and feature names from the glossary.
- *telefon* for a phone, *tablet*, *tv* (lowercase, the Danish spelling; definite *tv’et*) for
  the television as a device, *fjernbetjening* for the remote.
- On TV, prefer *Vælg* to *Tryk på*; for a button on the remote, write *Tryk på OK*. A remote
  button is the object of *Tryk på*, not the subject: *Tryk på Højre for at åbne panelet*.
- **Compounds are one word**, as Danish requires (*undertekstindstillinger*,
  *afspilningshastighed*, *serverindstillinger*, *brugerkonto*), never with an English-style
  space (*undertekst indstillinger*, *server indstillinger* are wrong). Join a loanword the same
  way (*streamkvalitet*, *pluginindstillinger*). Use a hyphen after an abbreviation, a number or
  a product or feature name, and after a name of more than one word put the hyphen only before
  the Danish part: *tv-serie*, *PIN-kode*, *HDR-video*, *4K-indhold*, *Jellyfin-server*,
  *Plex-bibliotek*, *Watch Party-invitation*, *Apple TV-appen*.
- English IT words that Danish uses as is stay English and take Danish endings: *server*,
  *stream* / *streame* / *streamet*, *download* / *downloade* / *downloadet*, *backup*,
  *plugin*, *app* / *apps*, *cache*, *log*, *token*. Sign in and out are *log ind* / *log ud*
  (*logget ind*), not *log på*.

## Keep as written

Code, file paths, URLs, environment variable and setting names, text in backticks, hostnames,
units (*Mbps*, *kbps*, *GB*), resolutions (*1080p*), codec, protocol and format names (in their
usual capitals, *HTTP*, *HLS*, even where the English lowercases them), and keyboard keys
(*Space*, *Enter*).

When a sentence names another screen, button, row, task or setting, use the Danish label that
element has in the catalog, not the English one. Write that label word for word, also inside a menu
path (*Settings → General → …*): don’t swap in a synonym or another wording of the same idea.
When the prompt lists the labels a string names, use the one on the string’s platform. The
glossary lists the names that recur.

## Plurals and numbers

- Plurals: `one other`. `one` is the number 1 (*1 film*, *1 afsnit*, *1 sæson*); `other` is
  everything else, including 0 (*0 afsnit*, *2 sæsoner*, *5 brugere*). Many Danish nouns have
  the same singular and plural (*film*, *afsnit*, *job*); still fill in both categories.
- Where the English prints `{count_text}` instead of `#`, keep `{count_text}`: the app formats
  that number.
- Digits come from the app; don't write numbers out or change separators.
- A number and its unit are separated by a space: *24 t*, *2 t 4 min*, *45 sek.*, *211 ms*,
  *7 d*, also after a number placeholder (*{minutes} min*). Never *m* for minutes. Percent takes
  a space too: *50 %*. In a short title where a line break would strand the unit, use a no-break
  space (U+00A0). An example of what to type into a field (*24h*, *30d, 2w, 6m*) is input syntax
  and stays exactly as written.

## Length

Danish runs longer than English, and long compounds can't break. Keys with `maxLength` appear on
TV and small controls. Stay within it: choose a shorter word or a shorter compound over an
abbreviation, and drop articles before abbreviating.

## Season and episode codes

Every season and episode code uses the same letters across the catalog (codes, tags, captions,
play buttons, Watch Party lines, notifications, admin pages): *S{season}A{episode}*,
*S{season} · A{episode}*, *S{season}:A{episode}*, *A{episode}* (S for sæson, A for afsnit, never
E). Keep the English separators (none, · or :).
