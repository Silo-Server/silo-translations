# Chinese, Simplified (zh-Hans)

- Address the user as **你**, not 您. Friendly and direct.
- Buttons are short verbs: *取消*, *保存*, *重试*.
- Full-width punctuation ，。：“” and the ellipsis …; no spaces between Chinese and Latin text
  except around product names when it reads better.
- Mainland vocabulary: *视频*, *服务器*, *设置*.
- Plurals: only `other`; use measure words (*# 季*, *# 项*).
