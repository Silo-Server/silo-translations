# Ukrainian (uk)

## Voice

- Address the user as **ви**, lowercase, with plural verb forms, as Apple, Google and Netflix do:
  *Увійдіть*, *Виберіть профіль*, *Спробуйте ще раз*. Never *ти*. Text that speaks to a group
  uses the same *ви* or the infinitive (*Дивіться разом, де б ви не були*).
- Buttons, menu items and the choices of a picker use the infinitive, consistently with the
  strings beside them: *Скасувати*, *Зберегти*, *Повторити спробу*, *Використовувати налаштування
  субтитрів*. Instructions in sentences use the *ви* imperative: *Виберіть бібліотеку*.
- An on/off value is *Увімк.* / *Вимк.*, whatever it switches (as Apple's Ukrainian settings
  do). A status sentence spells the word out: *Субтитри вимкнено*.
- Status words on one screen use the same form: a request's status is a short neuter participle
  or a noun (*Запитано*, *Схвалено*, *Відхилено*, *Помилка*, *Готово*), also in titles and
  labels on the same screen. For an impersonal result, prefer the *-но/-то* form (*Збережено*,
  *Видалено*, *Додано*) to a passive with *був*.
- Sentence case, like the English. Ukrainian doesn't capitalize nouns, weekdays or months.
  Feature names keep their own capitals (*Watch Party*, *Autoscan*). English all-caps labels
  stay all caps (*НАЖИВО* for LIVE).
- A library type or tab name used as a common noun inside a sentence is lowercase (*немає
  бібліотек фільмів*), not quoted as the tab name. When a sentence quotes a label, put it in
  «…».
- Quotation marks «…», with „…“ inside them. Write the ellipsis as one character ….
- The apostrophe is the typographic ’ (U+2019), never ASCII ' and never left out: *об’єкт*,
  *ім’я*, *пам’ять*, *під’єднати*, *з’єднання*, *комп’ютер*, *п’ять*.
- A dash between words is an en dash with spaces ( – ); a hyphen joins compounds (*онлайн-мітки*,
  *будь-який*, *PIN-код*).
- Be gender-neutral where it reads naturally. Ukrainian past tense and adjectives mark gender,
  so rephrase rather than pick one: *Ви ввійшли* (plural is neutral), *Учасник* → *хтось із
  учасників*, *гість*, *той, хто організовує*. Never write *він(вона)* or slash forms.

## Vocabulary

- Standard modern Ukrainian as Apple, Google and Netflix use it. Never use Russian words,
  Russian spellings or calques, and never a Russian letter (ы, э, ъ, ё). Common slips to avoid:

  | Avoid | Write |
  |---|---|
  | настройки, настроїти | налаштування, налаштувати |
  | відмінити (cancel) | скасувати |
  | удалити | видалити |
  | включити / виключити, включено | увімкнути / вимкнути, увімкнено |
  | переключити | перемкнути |
  | загрузка | завантаження |
  | найти, поиск | знайти, пошук |
  | получити | отримати |
  | попитка | спроба |
  | слідуючий | наступний |
  | на протязі | протягом |
  | являтися, являється | бути, є |
  | співпадати, співпадіння | збігатися, збіг |
  | в залежності від | залежно від |
  | по замовчуванню | за замовчуванням or типово |
  | на даний момент | наразі, зараз |
  | в якості | як |
  | так як (because) | оскільки, бо |
  | любий (any) | будь-який |
  | вірно, невірний (correct) | правильно, неправильний |
  | приймати участь | брати участь |
  | приймати рішення | ухвалювати рішення |
  | по причині | через |
  | діючий (current, valid) | чинний, поточний |
  | працюючий, відтворюючий (active participles) | що працює, який відтворюється |
  | вибачте за незручності | перепрошуємо |
  | додаток (an app) | застосунок |
  | співставити | зіставити |
  | розмір файлу складає | розмір файлу становить |
  | рахувати (consider) | вважати |
  | о 5 хвилин | через 5 хвилин |

- Use *у/в*, *і/й* and *з/із/зі* by euphony, as written Ukrainian does: *у профілі*, *в
  Android*, *і*, *й*.
- Established Ukrainian UI terms: *Налаштування*, *субтитри*, *бібліотека*, *завантажити*,
  *обліковий запис*, *пристрій*. Keep product and feature names from the glossary.
- *телефон* for a phone, *планшет*, *телевізор* for the TV as a device (*ТБ* where space is
  short), *пульт* for the remote.
- On TV, prefer *Виберіть* to *Натисніть*; for a button on the remote, write *Натисніть OK*. A
  remote button is the object of *Натисніть*, not the subject: *Натисніть «Праворуч», щоб
  відкрити панель*.
- English IT words that Ukrainian uses as is are written in Cyrillic as Ukrainian spells them:
  *сервер*, *плагін*, *вебхук*, *кеш*, *токен*, *логи* or *журнал*, *стрим* only in casual
  text (*потік* in settings). Names of products, protocols and formats stay in Latin.
- *Вебсторінка*, *вебінтерфейс*, *онлайн-*, *офлайн* follow the 2019 orthography (*веб* joined,
  no hyphen).

## Keep as written

Code, file paths, URLs, environment variable and setting names, text in backticks, hostnames,
resolutions (*1080p*), codec, protocol and format names (in their usual capitals, *HTTP*, *HLS*,
even where the English lowercases them), and keyboard keys (*Space*, *Enter*).

Units are written the Ukrainian way, as Apple and Google do: *ГБ*, *МБ*, *ТБ* (only as a
unit), *Мбіт/с*, *кбіт/с*, *мс*, *Гц*.

When a sentence names another screen, button, row, task or setting, use the Ukrainian label that
element has in the catalog, not the English one. Write that label word for word, also inside a menu
path (*Settings → General → …*): don’t swap in a synonym or another wording of the same idea.
When the prompt lists the labels a string names, use the one on the string’s platform. The
glossary lists the names that recur.

## Plurals and numbers

- Plurals: `one few many other`, from CLDR:
  - `one`: 1, 21, 31, 101 … (not 11): *# сезон*, *# епізод*, *# хвилина*
  - `few`: 2–4, 22–24, 32–34 … (not 12–14): *# сезони*, *# епізоди*, *# хвилини*
  - `many`: 0, 5–20, 25–30, 100 …: *# сезонів*, *# епізодів*, *# хвилин*
  - `other`: fractions only; use the genitive singular: *# сезону*, *# епізоду*, *# хвилини*
- `one` covers 21, 31 and 101 too, so every `one` form prints `#` (or the placeholder English
  prints). Never write *один*, *одна* or a form without the number, even where the English `one`
  leaves the number out (*Delete download* → `one {Видалити # завантаження}`).
- Adjectives and participles agree in each category: *# новий епізод*, *# нові епізоди*, *#
  нових епізодів*; *# вибраний*, *# вибрані*, *# вибраних*.
- Where the English prints `{count_text}` instead of `#`, keep `{count_text}`: the app formats
  that number.
- Digits come from the app; don't write numbers out or change separators.
- A number and its unit are separated by a space, without a full stop after the abbreviation:
  *24 год*, *2 год 4 хв*, *45 с*, *211 мс*, *7 дн.* (the only one with a full stop), also after
  a number placeholder (*{minutes} хв*). In a short title where a line break would strand the
  unit, use a no-break space (U+00A0). An example of what to type into a field (*24h*, *30d,
  2w, 6m*) is input syntax and stays exactly as written.

## Length

Ukrainian runs about 20–30% longer than English. Keys with `maxLength` appear on TV and small
controls. Stay within it: choose a shorter word (*Пуск*, *Далі*, *Назад*), drop a pronoun or a
preposition before abbreviating, and use the standard abbreviations (*хв*, *год*, *ТБ*, *Увімк.*)
only where the budget needs them.

## Season and episode codes

Every season and episode code uses the same letters across the catalog (codes, tags, captions,
play buttons, Watch Party lines, notifications, admin pages): *С{season}Е{episode}*,
*С{season} · Е{episode}*, *С{season}:Е{episode}*, *Е{episode}*, in Cyrillic (С for сезон, Е for
епізод), never Latin S and E. Keep the English separators (none, · or :). Spelled out, an
episode is *епізод*, never *серія*.
