# Croatian (hr)

## Voice

- Write standard Croatian: Latin script, ijekavian, Croatian vocabulary. Never Serbian or
  Bosnian forms (see "Croatian, not Serbian or Bosnian" below).
- Address the user formally, with the second person plural, as Apple's and Google's Croatian
  interfaces do: *Odaberite profil*, *Pokušajte ponovno.*, *Prijavite se*. Write *vi*, *vaš*
  in lowercase. Text that speaks to a group uses the same form.
- Buttons and menu items use the short imperative that Croatian interfaces use for commands:
  *Spremi*, *Odustani*, *Izbriši*, *Uredi*, *Pokušaj ponovno*, *Prijava* or *Prijavi se*.
  Keep the form consistent with the strings beside it. Instructions in sentences use the formal
  imperative: *Odaberite medijateku*.
- An on/off value is *Uključeno* / *Isključeno*, whatever it switches.
- Status words on one screen use the same form: a request's status is a neuter past participle
  (*Zatraženo*, *Odobreno*, *Odbijeno*, *Neuspjelo*), also in titles and labels on the same
  screen.
- Sentence case, like the English. Croatian lowercases languages, months and days of the week
  inside a sentence (*hrvatski*, *u ponedjeljak*, *15. studenoga*). Feature names keep their own
  capitals (*Watch Party*, *Autoscan*). English all-caps labels stay all caps (*LIVE*).
- A library type or tab name used as a common noun inside a sentence is lowercase (*nema
  medijateka s filmovima*), not quoted as the tab name.
- Quotation marks „…“ (low-high, as in Apple's Croatian). Write the ellipsis as one character ….
  Use the typographic apostrophe ’ where one is needed; Croatian rarely needs it.
- Be gender-neutral where it reads naturally. The formal plural already avoids the user's gender
  in past tenses (*Odjavili ste se*, *Dobro došli*), so prefer it to *Dobrodošao* or
  *Prijavljen si*. For third persons, rephrase (*osoba koja vodi party*, *gost*) rather than
  writing *korisnik/ca* or slashes.

## Vocabulary

- Established Croatian UI terms: *postavke*, *titlovi*, *medijateka*, *preuzimanje*,
  *datoteka*, *zaslon*, *poslužitelj*. Keep product and feature names from the glossary.
- *telefon* for a phone, *tablet*, *TV* (uppercase) or *televizor* for the television as a
  device, *daljinski upravljač* (*daljinski* where space is short) for the remote.
- On TV, prefer *Odaberite* to *Pritisnite*; for a button on the remote, write *Pritisnite OK*.
  A remote button is the object of *Pritisnite*, not the subject: *Pritisnite Desno da biste
  otvorili ploču*.
- English IT words that Croatian uses as is: *stream* (declined without a hyphen: *streama*,
  *streamu*), *streaming*, *token*, *webhook*, *API*. Prefer the Croatian word where Apple and
  Google use one: *dodatak* (plugin), *sigurnosna kopija* (backup), *zapisnik* (log),
  *predmemorija* (cache), *transkodiranje* (transcoding).
- Decline foreign names normally where Croatian would (*u Plexu*, *s Jellyfina*), but leave
  names that end oddly undeclined or put them after a noun (*u aplikaciji Infuse*).

## Keep as written

Code, file paths, URLs, environment variable and setting names, text in backticks, hostnames,
units (*Mbps*, *kbps*, *GB*), resolutions (*1080p*), codec, protocol and format names (in their
usual capitals, *HTTP*, *HLS*, even where the English lowercases them), and keyboard keys
(*Space*, *Enter*).

When a sentence names another screen, button, row, task or setting, use the Croatian label that
element has in the catalog, not the English one. Write that label word for word, also inside a menu
path (*Settings → General → …*): don’t swap in a synonym or another wording of the same idea.
When the prompt lists the labels a string names, use the one on the string’s platform. The
glossary lists the names that recur.

## Plurals and numbers

- Plurals: `one few other`. The categories follow the last digits, not the number itself:
  - `one`: 1, 21, 31, 101… (not 11). Noun in nominative singular: *# epizoda*, *# sezona*,
    *# film*.
  - `few`: 2–4, 22–24, 32–34… (not 12–14). Genitive singular: *# epizode*, *# sezone*,
    *# filma*.
  - `other`: 0, 5–20, 25–30, 100… Genitive plural: *# epizoda*, *# sezona*, *# filmova*.
- Because `one` also covers 21, 31 and so on, a `one` form never spells out *jedan*, *jedna*
  or *jedno*, and never says *ovaj* / *ova* as if the count were exactly 1. Write `#` (or the
  placeholder the English uses, such as `{count_text}`). Where the English `one` form leaves the
  number out (*This signs out of its account.*), put the number in the Croatian `one` form.
- Verbs and participles agree with the form: *# epizoda je preuzeta*, *# epizode su preuzete*,
  *# epizoda je preuzeto* (neuter singular after 5 and up). Example:
  `{count, plural, one {# epizoda} few {# epizode} other {# epizoda}}`.
- Where the English prints `{count_text}` instead of `#`, keep `{count_text}`: the app formats
  that number.
- Digits come from the app; don't write numbers out or change separators.
- A number and its unit are separated by a space: *24 h*, *2 h 4 min*, *45 s*, *211 ms*,
  *7 d*, also after a number placeholder (*{minutes} min*). Never *m* for minutes. In a short
  title where a line break would strand the unit, use a no-break space (U+00A0). An example of
  what to type into a field (*24h*, *30d, 2w, 6m*) is input syntax and stays exactly as written.

## Length

Croatian runs longer than English. Keys with `maxLength` appear on TV and small controls. Stay
within it: choose a shorter word or rephrase (*Postavke* rather than *Postavke reprodukcije*
when the screen already says playback) before abbreviating, and avoid abbreviations a reader
would not recognise.

## Season and episode codes

Every season and episode code uses the same letters across the catalog (codes, tags, captions,
play buttons, Watch Party lines, notifications, admin pages): *S{season}E{episode}*,
*S{season} · E{episode}*, *S{season}:E{episode}*, *E{episode}* (S for sezona, E for epizoda,
as in the English). Keep the English separators (none, · or :).
