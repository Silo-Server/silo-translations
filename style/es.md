# Spanish (es)

- One neutral Spanish for Spain and Latin America. Avoid words that belong to one region
  (*ordenador*/*computadora*: prefer *equipo* or *dispositivo*; *vídeo* with the accent is
  fine in both).
- Address the user as **tú**: *Inicia sesión*, *Elige un perfil*. Never *usted* or *vosotros*.
- Buttons and menu items use the infinitive or imperative consistently with nearby strings:
  *Cancelar*, *Guardar*, *Reintentar*.
- Sentence case, like the English. Use « » only if the English quotes something; otherwise
  “ ”.
- Plurals: `one many other`; `many` is for whole millions (*1 000 000 de temporadas*).
