# Portuguese, Brazil (pt-BR)

- Brazilian Portuguese, not European. Address the user as **você**, usually implied by the
  verb: *Entre na sua conta*, *Escolha um perfil*.
- Buttons use the infinitive: *Cancelar*, *Salvar*, *Tentar novamente*.
- Brazilian vocabulary: *tela*, *celular*, *arquivo*, *baixar*.
- Sentence case, like the English. Quotation marks “ ”.
- Plurals: `one many other`. `one` covers 0 and 1; `many` is for whole millions
  (*1.000.000 de temporadas*).
