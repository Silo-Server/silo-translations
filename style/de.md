# German (de)

- Address the user as **du**, lowercase: *Melde dich an*, *Wähle ein Profil*. Never *Sie*.
- Buttons use the infinitive: *Abbrechen*, *Speichern*, *Erneut versuchen*.
- Prefer established German UI terms over anglicisms where they are common (*Einstellungen*,
  *Untertitel*), but keep product and feature names from the glossary.
- German runs long. Respect `maxLength`; choose shorter synonyms over abbreviations.
- Quotation marks „…“. Sentence case, nouns capitalized as German requires.
